## 1. Шийдвэрүүд

- **Стек:** `App/`-тай ижил (Expo 57). Хуваалцах кодыг (`apiResult`, `httpClient`, `jwt`, `apiConfig`, `theme`) эхэндээ `nurse-app/` руу **хуулна**. Monorepo/shared package нээлтээс хойш (v1.1).
- **Тусдаа апп:** spec слайд 7-ийн зөвлөмж. Store-д хоёр бүртгэл.
- **Нэвтрэлт:** backend одоогоор NURSE-д зөвхөн имэйл + нууц үг (`POST /api/auth/login`) өгдөг. OTP нь зөвхөн CHILD (B1).
- **Төлөв:** сервер эх үнэн. Апп `version`-тай (optimistic lock) үйлдэл илгээнэ, `409 VERSION_CONFLICT` ирвэл дахин ачаална.

Шалгасан зүйл: CHILD нэвтрэлт татгалзагдаж session хадгалагдахгүй; NURSE зөвхөн өөрийн захиалгыг харна, бусдынх 404; ETA (өнгөрсөн нь татгалзагдана); хуучин `version` → `VERSION_CONFLICT`; `ASSIGNED → IN_PROGRESS → COMPLETED`; эхлүүлэхээс өмнө дуусгах → `INVALID_STATUS`; бусдын захиалгыг эхлүүлэх боломжгүй.
