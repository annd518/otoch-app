## 3. Тест дугаар (store review, staging tester)

Сувилагчийн апп SMS-ээр нэвтэрдэг. Apple/Google review болон staging tester SMS авч чадахгүй тул:

1. Дансыг бүртгэнэ: `npm run nurse:provision -- +97699XXXXXXX "Тест сувилагч"` (серверийн `DATABASE_URL`-тэй орчинд).
2. Тогтмол кодыг серверийн `OTP_TEST_ACCOUNTS`-д нэмнэ: `+97699XXXXXXX:NNNNNN` (кодыг санамсаргүй үүсгэх; `123456`, `111111` төрлийн энгийн код тоологдохгүй). Ийм дугаарт SMS явахгүй.
3. Review notes: «Нэвтрэх: утасны дугаар + дээрх код. Тест дугаарт SMS явахгүй.» Кодыг нууц гэж үзэж, tester бүрт хувиар өгнө.
4. Тест захиалга: staging-д админ (wclient) үйлчлүүлэгчийн захиалгыг тест сувилагчид томилно (`/api/staff/orders/:id/assign`). Эс бөгөөс апп хоосон жагсаалт харуулна. Дугаар тус бүрт тус тусдаа данс байх ёстой (нэг дугаар нэг данс).

## 4. Бодит төхөөрөмж дээрх шалгалт (гараар; хараахан хийгээгүй)

Бэлтгэл: staging сервер, 3 тест дугаар, 2 тест захиалга (нэг нь дэлгэцийн дагуу, нэг нь хэвийн), Android болон iPhone тус бүр. Тэмдэглэх: ✅/❌ + төхөөрөмж, OS, огноо.

| # | Шалгалт | Хүлээгдэх үр дүн |
|---|---|---|
| 1 | Утасны дугаар → код авах → нэвтрэх | Жагсаалт гарна; буруу код 3 удаа → «15 минутын дараа» |
| 2 | Нэвтэрсэн, аппыг хаагаад дахин нээх | Дахин нэвтрэхгүй |
| 3 | 15+ минут идэвхгүй, дараа жагсаалт шинэчлэх | Автоматаар refresh хийгдэж нэвтэрсэн хэвээр |
| 4 | Нислэгийн горим → жагсаалт шинэчлэх | Хадгалагдсан жагсаалт + улбар шар баннер; нэвтрэлт алдагдахгүй |
| 5 | Үйлчлүүлэгчийн (CHILD) дугаараар нэвтрэх | «Энэ апп зөвхөн сувилагчид» |
| 6 | Дэлгэрэнгүй: газрын зураг, «Залгах», заалтын зураг | Газрын зураг нээгдэнэ; залгах dialer-д; зураг харагдана |
| 7 | «Замдаа гарлаа», ETA сонгох | Үйлчлүүлэгчийн апп-д `Замдаа` төлөв |
| 8 | Check-in: байршил зөвшөөрөл өгөхгүй | Тайлбар + «Тохиргоо нээх» |
| 9 | Check-in хаягаас > 200 м | «200 м-ийн дотор очиж эхлүүлнэ» |
| 10 | Check-in хаяг дээр, цагийн ±30 мин дотор | Тэмдэглэлийн дэлгэц |
| 11 | Тэмдэглэл: хэт өндөр утга (SpO₂ 150) | Талбарт алдаа, хадгалагдахгүй |
| 12 | Тэмдэглэл бөглөөд аппыг хаагаад дахин нээх | Хадгалсан утгууд сэргээгдэнэ |
| 13 | Гарын үсэг: хуруугаар зурах, арилгах, scroll хоцрохгүй | PNG зөв үүснэ, дуусгалт амжилттай |

**Мэдэгдэж буй хязгаарлалт (шалгалтад бүү гайхаарай):** push мэдэгдэл байхгүй (v1.1), offline үед тэмдэглэл зөвхөн сервер рүү хадгалагддаг (offline draft v1.1), QR үнэмлэх байхгүй (check-in зөвхөн байршил+цаг), гарын үсгийн талбар дэлгэц уншигчид зориулсан өөр хувилбаргүй (нүдний хараагүй хэрэглэгчийн хувьд хүнтэй хамт зурах хэрэгтэй, ⚑ хүртээмжийн шийдвэр).

## 5. Store, нууцлал (нэмэлт хэсэг)

[store-listing-draft.md](release/store-listing-draft.md), [privacy-policy-draft.md](release/privacy-policy-draft.md) нь үйлчлүүлэгчийн апп-д зориулсан. Сувилагчийн апп-д нэмэх:

- **Цуглуулах өгөгдөл:** нэр, утасны дугаар (нэвтрэлт), **яг байршил** (зөвхөн check-in товч дарсан агшинд, хаягтай тулгахад; background байхгүй), эргэлтийн тэмдэглэл (амин үзүүлэлт, ажилбар, эм шалгалт, гарын үсэг), үйлчлүүлэгчийн нэр, утас, хаяг, заалтын зураг (харах эрхтэй).
- **Apple Privacy Nutrition Label / Google Data Safety:** Precise Location, Health & Fitness (үйлчлүүлэгчийн мэдээлэл), Contact info, User content (гарын үсэг), Identifiers. Гуравдагч SDK-д дамжуулахгүй; push, analytics SDK байхгүй. Хариултыг эрх зүйч баталгаажуулна.
- **Нэр, тайлбар:** «ОТОЧ Сувилагч» гэх мэт. «Эмнэлэг», «эмчлэх», «яаралтай» хэллэг бүү ашигла (слайд 10). Апп нь зөвхөн баталгаажсан, админаас бүртгэгдсэн сувилагчид гэдгийг дурд.
- **Review notes:** §3-ын тест дугаар + «Account is created by the company; there is no public sign-up. Location is used only at check-in.»
