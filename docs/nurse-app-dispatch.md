# nurse-app: томилолт (dispatch) ба сувилагчийн профайл

| Талбар | Утга |
|---|---|
| Огноо | 2026-10-19 |
| Эх сурвалж | spec v2.0 слайд 35 (сувилагчийн шаардлага), 70 (state machine), 82 (N04) |
| Нотолгоо | Серверийн 186 тест (энэ ажлаар 17 нэмэгдсэн: `nurse-dispatch` 15, `nurse-provision` +2), nurse-app 60 тест, typecheck, lint, bundle, `expo-doctor`; бодит серверийн түр хуулбар дээр (dispatch loop асаалттай) интеграци 9/9. **Бодит төхөөрөмж, push, үйлдвэрлэлийн өгөгдөл дээр шалгаагүй** |

## 1. Урсгал

```
төлбөр төлөгдсөн (PAID)  ─►  dispatch давалгаа 1: 3 сувилагч, 120 сек
        │                         │ хүлээн авсан ─► ASSIGNED (бусдынх CANCELLED)
        │                         │ татгалзсан / хугацаа дууссан ─► давалгаа 2 (асуугаагүй сувилагчид)
        └─ хэн ч аваагүй ─► PAID хэвээр, админ гараар томилно (`/api/staff/orders/:id/assign`)
```

Тохиргоо (`server/src/services/dispatch.ts`): `OFFER_TTL_MS` 120 сек, `WAVE_SIZE` 3, `DISPATCH_HORIZON_MS` 24 цаг (эхлэхээс 24 цагийн дотор л илгээнэ), `CONFLICT_WINDOW_MS` 2 цаг, `NURSE_SHARE_PERCENT` 70.

## 2. Санал авах эрхтэй сувилагч (сервер дээр заавал шалгана)

`VERIFIED` ∧ зөвшөөрлийн хугацаа дуусаагүй ∧ өөрөө «идэвхтэй» болсон ∧ шаардлагатай ур чадвартай (S02 → `INJ`, S03/S08 → `IV`, S04 → `WOUND`, S09 → `CATH`, S10 → `NG`, S06/S07 → `CARE`, S01/S05 → шаардлагагүй) ∧ бүс таарна (хоосон = бүх бүс) ∧ ±2 цагт өөр дуудлагагүй ∧ устгагдаагүй. Хүлээн авах үед **дахин шалгана** (санал илгээгдсэнээс хойш `SUSPENDED` болсон бол `409 NOT_ELIGIBLE`).

Эхэлж ачаалал бага сувилагчаас асууна. Давхар хүлээн авалтад мөр түгжээ ба `(order, nurse)` unique хамгаална: зэрэг хүлээн авбал яг нэг нь амжилтад хүрнэ (тест).

## 3. API (`/api/nurse`, зөвхөн NURSE)

| Endpoint | Хэрэг |
|---|---|
| `GET /offers` | Миний хүчинтэй саналууд: үйлчилгээ, цаг, **бүс** (яг хаяггүй), `secondsLeft`, орлого (≈ 70%) |
| `POST /offers/:id/accept` | Хүлээн авна. Хариунд захиалга + **хаяг**. `409 OFFER_EXPIRED` / `ORDER_TAKEN` / `NOT_ELIGIBLE` |
| `POST /offers/:id/decline` | Татгалзана |
| `GET /me`, `PUT /me {isActive}` | Профайл, онлайн toggle. Баталгаажаагүй, зөвшөөрөл дууссан бол асаах боломжгүй (`409 NOT_ELIGIBLE` + шалтгаан); унтраах нь үргэлж боломжтой |

Нууцлал: санал дээр яг хаяг, утас **харагдахгүй**; зөвхөн хүлээн авсны дараа.

## 4. Сувилагч бүртгэх, баталгаажуулах (админ/хөгжүүлэгч)

```
npm run nurse:provision -- +97699112233 "Б.Номин" --verified --license 10387 \
    --expires 2028-05-31 --skills INJ,IV,WOUND --zones Z1,Z2
```

`--verified`-гүй бол `PENDING`: нэвтэрч чадна ч санал авахгүй. Баталгаажуулалт нь админ зөвшөөрлийг бүртгэлтэй тулгасны гэрчлэл (спек слайд 35); энэ script тулгалт хийхгүй. Зөвшөөрөл дуусах 30/7 хоногийн сануулга, дуусмагц автоматаар `SUSPENDED` болгох нь **хараахан хийгдээгүй** (хугацаа дууссан сувилагч санал авахгүй, гэхдээ статус автоматаар солигдохгүй).

## 5. Ажиллуулах

Dispatch нь API процесс доторх `setInterval` (`DISPATCH_INTERVAL_MS`, анхдагч 15000, `0` = унтраана; тест болон `app.ts` дотор ажиллахгүй, зөвхөн `index.ts`). Хэд хэдэн instance зэрэг ажиллахад аюулгүй. **Push мэдэгдэл байхгүй:** апп «Дуудлага» таб нээлттэй үед 8 секунд тутам асууна. Апп хаалттай/дэвсгэрт байвал сувилагч санал харахгүй, 120 секундэд хугацаа дуусна. Бодит ашиглалтад FCM push (spec: v1.1) заавал хэрэгтэй.

## 6. Мэдэгдэж буй хязгаарлалт

- Зай харуулахгүй (сувилагчийн байршил серверт хадгалагддаггүй; байршил ping нь нууцлалын шийдвэр хүлээж буй).
- «15 минутад админд сэрэмжлүүлэг», `EXPIRED` захиалга, үйлчлүүлэгчид санал (spec слайд 70) хийгдээгүй: хэн ч авахгүй бол захиалга `PAID` хэвээр.
- Сувилагчийн татгалзсан шалтгаан, 3 удаа дараалан татгалзвал сануулга/торгууль байхгүй.
- wclient-д санал, сувилагчийн профайл удирдах дэлгэц байхгүй (зөвхөн script).
- Орлого нь `Quote.subtotalMnt × 70%`-ийн тооцоо (бүсийн хураамж, шимтгэлийн эцсийн гэрээ ⚑ баталгаажаагүй).

## 7. Бодит төхөөрөмж дээр нэмэх шалгалт (гараар)

| # | Шалгалт | Хүлээгдэх үр дүн |
|---|---|---|
| 19 | Профайл → «Дуудлага хүлээн авах» асаах (баталгаажсан) | Асна; баталгаажаагүй бол шалтгаан харагдана |
| 20 | Төлөгдсөн захиалга үүсгэх (таны цаг ≤ 24 цаг) | 8 сек дотор «Шинэ дуудлага» карт, тоолуур буурна |
| 21 | Хоёр утсаар зэрэг «Хүлээн авах» | Нэг нь захиалгын дэлгэцэнд, нөгөө нь «өөр сувилагч авсан/хүчингүй» мэдээлэл авна |
| 22 | Татгалзах | Карт арилна, дахин ирэхгүй |
| 23 | 2 минут хүлээх | Карт арилна; нөгөө асаалттай сувилагчид давалгаа 2 ирнэ |
