## Import хийхэд бэлэн

- `server/content/approved/questionnaire-v2.json`: шинэ immutable questionnaire version, зургаан эх асуулт, чат дахь approval.
- `server/content/approved/catalog-v2.json`: батлагдсан 10 үйлчилгээ, үнэ, metadata/config; дээрх questionnaire-г холбоно; `formConfig.approved: true`.
- Fixture seed/test data-г approved болгож хувиргаагүй. Approved багцыг DB-д импортолсны дараа API `isFixture:false`, approval:true буцаана. Одоогийн DB-д apply/seed хийгдээгүй.

```sh
cd server
npm run content:import -- content/approved/questionnaire-v2.json --dry-run
npm run content:import -- content/approved/catalog-v2.json --dry-run
# Зорилтот DB backup болон apply-ийн өмнөх зөвшөөрлийн дараа:
npm run content:import -- content/approved/questionnaire-v2.json --apply
npm run content:import -- content/approved/catalog-v2.json --apply
```

Зөвхөн түр UTF8 тест DB-д import хийж, API-аас батлагдсан төлөвөөр гарч байгааг шалгана. Production fixture хамгаалалтыг сулруулахгүй.

## Эх сурвалжид байхгүй эсвэл кодын ажил үлдсэн зүйл

Баталгаа дутуу биш, **утга нь баримтад байхгүй**: бүсийн бодит полигон/зай тооцох эхлэл координат, бодит slot/capacity, нийтлэгдсэн нөхцөл/бодлогын URL, хугацаа сунгалтын мөнгөн дүн. Эдгээрийг зохиож нөхөхгүй.

Үнийн дүрмүүд батлагдсан боловч энэ import нь quote-ийн бүсийн нэмэгдэл, add-on хөнгөлөлт, payout ledger, цуцлалтын логикийг шинээр хэрэгжүүлэхгүй. Одоогийн quote бүсийн хураамж тооцохгүй. Баримтын дүрэмтэй нийцүүлэх кодын ажил тусдаа үлдсэн; импорт бэлэн болсныг тэр боломжууд ажилласан гэж тооцохгүй.

Эх өөрөө зөрүүтэй: RF6-г 27-д «оврогын», 33-д товчилсон; 27-ийн яг найруулгыг хадгалав. S03 гэр бүлийн нөхцөл нь JSON/матрицад recommended боловч preparation-д заавал мэт бичсэн; матрицыг ашиглав. PDF х.34 нь JPEG ≤5MB/EXIF цэвэрлэх, өмнөх хэрэгжүүлэх төлөвлөгөө JPEG/PNG ≤10MB гэж заасан; upload API-г энэ агуулгын өөрчлөлтөөр солиогүй. Эдгээр техникийн зөрүүг нуухгүй.

Нийт 1–5 🟡: агуулгын approval gate хаагдсан, харин DB publication, бодит pricing-ийн үлдсэн логик, staging/private bucket/төхөөрөмжийн acceptance дуусаагүй.
